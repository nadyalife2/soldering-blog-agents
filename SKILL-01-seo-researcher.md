# Бот №1 — SEO-Исследователь (seo-content-optimizer)

Задача: наполнять таблицу `semantic_core` свежими данными о конкурентах, темах и
интерактивных фишках. Работает один раз в неделю, даёт топливо для Бота №2.

## Что делает с таблицей

| Лист | Действие |
|---|---|
| `competitors` | Добавляет новые сайты, обновляет существующие |
| `raw_data` | Добавляет URL, H1, тип контента, кластер, приоритет, статус |
| `content_plan` | Добавляет новые темы, проверяет дубликаты по колонке `slug` |
| `interlinking_map` | Строит Hub-and-Spoke матрицу с русскими анкорами |

В каждой изменённой строке ставит `дата_обновления = YYYY-MM-DD`.

---

## Шаг 1: Поиск новых конкурентов и фишечек

1. Выполни поисковые запросы по нише пайки и ремонта электроники:
   - `пайка электроники гайд 2026`
   - `калькулятор подбора флюса`
   - `подборщик паяльных жал сайт`
   - `обзор паяльных станций блог`
   - `ремонт плат своими руками форум`
2. Найди интерактивные инструменты на конкурентах:
   калькуляторы, подборщики, диагностические виджеты, таблицы совместимости.
3. Запиши в `competitors`:

```
домен | ниша | тип | раздел_блога | кол-во_статей |
интерактивные_фишки | заметки | дата_обновления
```

---

## Шаг 2: Глубокий краулинг (Firecrawl Protocol)

1. Обойди sitemap конкурентов, извлеки URL, H1/H2, даты публикации, виджеты.
2. Запиши в `raw_data`:

```
url | title | h1 | date | source | content_type |
cluster | priority | status | дата_обновления
```

Статус новой строки = `собрано`.

---

## Шаг 3: Аудит content_plan и duplicate guard

1. Загрузи `content_plan`.
2. Проверь дубликаты: сравни `slug` новых тем с существующими в `content_plan`.
   Slug = единственный мастер-идентификатор (Бот №2 проверяет по нему же).
3. Добавь новые высокоприоритетные темы и идеи интерактивных фишечек.
4. Формат новой строки в `content_plan`:

```
ID_темы | рабочий_заголовок | slug | кластер | приоритет |
интент | статус | перелинковка | дата_обновления
```

> ⚠️ Slug — только латиница, цифры и дефисы: `[a-z0-9-]+`.
> Перед записью проверить regex. Если slug содержит кириллицу — не записывать, исправить.

---

## Шаг 4: Hub-and-Spoke интерлинкинг

1. Определи Hub-статьи (топ-уровень) и Spoke-статьи (под-темы) по кластерам.
2. Для каждой пары: Hub→Spoke и Spoke→Hub — запиши в `interlinking_map`:

```
ID_источника | slug_источника | ID_цели | slug_цели |
анкорный_текст | тип_связи (hub→spoke / spoke→hub) | дата_обновления
```

Анкоры — живые русские фразы, не "нажмите здесь" и не URL.

---

## Шаг 5: Финальная запись

1. Проставь `дата_обновления = YYYY-MM-DD` во ВСЕХ изменённых строках всех листов.
2. Сохрани `semantic_core` на Google Drive.
3. Синхронизируй Google Sheet через `sheets_agent:call`.
