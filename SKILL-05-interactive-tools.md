# Бот №5 — Генератор интерактивных инструментов (solder-interactive-tools)

**Задача:** по slug инструмента из листа `interactive_tools` сгенерировать полный HTML/JS-код (без бэкенда, без платных сервисов) и документацию для встройки в WordPress-страницу.

Все инструменты — **чистый JS или React**, без бэкенда, без внешних API с платными лимитами. Максимально дёшево и быстро.

---

## ПРИОРИТЕТЫ

| # | Принцип | Правило |
|--|--|--|
| 1 | **Дёшево** | Только бесплатные технологии. Vanilla JS — по умолчанию. React — только если UX требует. |
| 2 | **Быстро** | Core Web Vitals: LCP < 2.5s. Никакого тяжёлого бандла. |
| 3 | **Красиво** | CSS-переменные сайта, адаптив от 320px, hover-состояния. |
| 4 | **SEO** | Статический fallback для краулеров. JSON-LD для HowTo/FAQ если применимо. |
| 5 | **Перелинковка** | Каждый результат содержит ссылку на связанную статью. |

## База данных: 13 инструментов

> Источник правды — лист `interactive_tools` в `semantic_core.xlsx`.
> Здесь — краткий справочник для агента.

### 🔴 Высокий приоритет (делать первыми)

#### 1. Подборщик флюса (`/podbor-flyusa/`)
- **UX:** Wizard 3 шага — `что паяешь` → `тип металла` → `есть ли смывка`
- **Входные параметры:** что паяешь (dropdown: провода / DIP / SMD 0402+ / BGA / нержавейка); тип металла (медь / сплав / сталь / золото); есть ли возможность промыть (да / нет)
- **Выход:** марка флюса + тип (RMA/RA/No-clean) + температура активации + нужна ли смывка + ссылка на статью
- **Технология:** Vanilla JS + JSON-объект с логикой выбора (~80 строк)
- **Связанные статьи:** `flyus-dlya-pajki-kakoj-vybrat`, `kanifol-ili-zhidkij-flyus`
- **SEO-ловушка:** 3 000+ запросов/мес на «какой флюс выбрать»

#### 2. Подборщик припоя (`/podbor-pripoya/`)
- **UX:** Форма + мгновенный результат
- **Входные параметры:** задача (dropdown: электроника / провода / сантехника / ювелирка); RoHS нужен (да/нет); навык (новичок / опытный); флюс внутри нужен (да/нет)
- **Выход:** марка (ПОС-61 / SAC305 / Sn63Pb37 / Bi-Sn) + диаметр + t° плавления + пояснение
- **Технология:** Vanilla JS + lookup JSON таблица (~60 строк)
- **Связанные статьи:** `pripoj-dlya-pajki-vidy`, `pos-61-i-pos-40-raznica`

#### 3. Калькулятор температуры жала (`/kalkulator-temperatury-pajki/`)
- **UX:** Слайдеры + instant result + цветовые предупреждения
- **Входные параметры:** тип припоя (ПОС-61 / SAC305 / Bi-Sn / свинцовый); размер контакта (S=0402/resistor / M=DIP-pin / L=ground-plane); тип жала (конус / долото / нож / T-tip); мощность паяльника (Вт: 20–100)
- **Выход:** рекомендуемая t° + диапазон + ⚠️ предупреждение если параметры конфликтуют
- **Технология:** Vanilla JS, формула на основе таблиц JEDEC
- **Связанные статьи:** `kak-payat-payalnikom`, `moschnost-payalnika`

#### 4. Подборщик паяльника (`/podbor-payalnika/`)
- **UX:** Квиз 4 шага → карточка результата
- **Входные параметры:** задача (домашний ремонт / электроника / SMD профессионально / образование); бюджет (₽: слайдер 500–15 000); нужен ли фен (да/нет); опыт (новичок / средний / профи)
- **Выход:** конкретная модель (TS101 / Pinecil V2 / KSGER T12 / Hakko FX-888D) + обоснование + ссылка на обзор + партнёрские ссылки (если есть)
- **Технология:** React wizard (4 компонента) или Vanilla JS если нет React в теме
- **Связанные статьи:** `kakoj-payalnik-vybrat`, `luchshie-payalniki-dlya-doma`
- **Монетизация:** партнёрские ссылки на Яндекс.Маркет / Aliexpress

### 🟡 Средний приоритет

#### 5. Диагностика дефекта пайки (`/diagnostika-defekta/`)
- **UX:** Симптомы-чекбоксы → раскрывающийся диагноз
- **Симптомы:** матовый/серый спай; мост припоя; припой скатывается; плохой прогрев; перегрев компонента; чёрное жало; трещина спая
- **Выход:** диагноз + причина + пошаговое решение + ссылка
- **Технология:** Vanilla JS + CSS аккордеон
- **Связанные статьи:** `oshibki-novichka-pri-pajke`, `holodnaya-pajka`

#### 6. Таблица совместимости жал (`/tablica-zhala-payalniki/`)
- **UX:** Dropdown выбора паяльника → фильтруемая таблица жал
- **Паяльники:** T12 (KSGER/Quicko); 900M (Hakko клоны); JBC C245; Hakko FX-888D; TS101/Pinecil (TS-серия)
- **Выход:** тип жала + артикул + цена (диапазон) + где купить
- **Технология:** JS DataTables или простой filter()
- **База данных:** ~50 позиций в JSON
- **Связанные статьи:** `zhalo-dlya-payalnika-tipy`, `kak-chistit-zhalo`

#### 7. Калькулятор мощности паяльника (`/kalkulator-moschnosti/`)
- **UX:** 3 поля + кнопка = результат
- **Входные параметры:** тип работы (пайка SMD / DIP / провода / земля / нержавейка); материал (медь / алюминий / сталь / FR4); толщина/сечение (мм или мм²)
- **Выход:** рекомендуемая мощность (Вт) + объяснение почему
- **Технология:** Vanilla JS формула
- **Связанные статьи:** `moschnost-payalnika-dlya-zadach`

#### 8. Паста или проволока (`/pasta-ili-provod/`)
- **UX:** Радиокнопки + instant result
- **Входные параметры:** тип монтажа (SMD / DIP / смешанный); есть ли фен/термофен (да/нет); тип корпуса (QFP/TQFP / 0402–0603 / DIP / через-дырочный)
- **Выход:** рекомендация (паста / проволока / оба) + объяснение + ссылка
- **Технология:** Vanilla JS + inline result block
- **Связанные статьи:** `payalnaya-pasta-ili-pripoj`, `smd-pajka`

#### 9. Тест «Проверь свою пайку» (`/test-svoya-pajka/`)
- **UX:** 10 вопросов с изображениями → балл + разбор
- **Механика:** показать фото спая → угадать: хороший / холодный / мост / перегрев / скатился
- **Выход:** балл 0–10 + разбор каждой ошибки + персональная рекомендация статьи
- **Технология:** JS квиз + SVG-иллюстрации или фото
- **Вирусный потенциал:** шеринг результата «Я набрал 8/10 на тесте по пайке»
- **Связанные статьи:** `oshibki-novichka-pri-pajke`, `kak-payat-payalnikom`

- **Технология:** 5 строк JS

- **UX:** Мультиселект 2–3 станции → динамическая таблица бок-о-бок
- **Параметры сравнения:** мощность (Вт); типы жал; ESD-защита; наличие фена; цена (₽); оценка редакции
- **База:** ~15 моделей в JSON
- **Технология:** JS динамическая таблица
- **Связанные статьи:** `payalnaya-stanciya-ili-payalnik`

#### 12. Чеклист перед первой пайкой (`/cheklistt-pered-pajkoj/`)
- **UX:** Чекбоксы + прогресс-бар
- **Пункты:** паяльник ✓; флюс ✓; припой ✓; подставка ✓; пинцет ✓; освещение ✓; вентиляция ✓; лупа/очки ✓
- **Выход:** прогресс-бар + «ты готов!» или «не хватает: [список]»
- **Технология:** JS + localStorage (сохраняет состояние между визитами)
- **Связанные статьи:** `kak-payat-payalnikom`, `s-chego-nachat-pajku`

#### 13. Глоссарий пайки (`/glossarij-pajki/`)
- **UX:** Строка поиска + мгновенная фильтрация
- **База:** ~100 терминов: флюс, интерметаллид, адгезия, SMD, DIP, реболлинг, BGA, жало, спай, холодная пайка...
- **Выход:** термин + определение (1–2 предложения) + ссылка на статью
- **Технология:** Fuse.js (3 KB) или нативный JS filter()
- **Связанные статьи:** все кластеры

## Алгоритм генерации инструмента

При команде `/tool <slug>`:

1. **Найти инструмент** в таблице выше по slug.
2. **Определить UX-паттерн**: wizard / форма / квиз / таблица / чекбоксы / поиск.
3. **Сгенерировать:**
   - `index.html` — разметка (семантичная, доступная, WAI-ARIA)
   - `tool.js` — логика без зависимостей (или минимальные: Fuse.js ≤ 10 KB)
   - `tool.css` — стили с CSS-переменными (`--color-primary`, `--color-accent`)
4. **Встроить SEO-обёртку:**
   - `<h1>` совпадает с H1 связанной страницы
   - JSON-LD `SoftwareApplication` или `HowTo` (где применимо)
   - Ссылки на все связанные slug-статьи
5. **Проверить:**
   - Работает без JS (graceful degradation или fallback-текст)
   - Адаптив от 320px
   - LCP < 2.5s (нет тяжёлых внешних ресурсов)
6. **Экспортировать** в `wp_export` лист: добавить строку с кодом инструмента, slug, датой.

## Шаблон кода: Wizard (пример для Подборщика флюса)

```html
<!-- flux-picker.html -->
<div id="flux-picker" class="tool-wizard" role="application" aria-label="Подборщик флюса">
  <div class="wizard-step" data-step="1">
    <h2>Что вы паяете?</h2>
    <div class="choices">
      <button data-value="wires">Провода</button>
      <button data-value="dip">DIP-компоненты</button>
      <button data-value="smd">SMD (0402 и мельче)</button>
      <button data-value="bga">BGA / реболлинг</button>
      <button data-value="steel">Нержавейка / сталь</button>
    </div>
  </div>
  <!-- steps 2, 3 аналогично -->
  <div class="wizard-result" hidden>
    <h2>Ваш флюс:</h2>
    <p id="flux-name"></p>
    <p id="flux-explanation"></p>
    <a id="flux-article-link">Подробнее →</a>
  </div>
</div>
```

```javascript
// flux-picker.js
const FLUX_DB = {
  wires_copper_yes:    { name: "Канифоль в спирте (СКФ)", type: "RMA", wash: false, link: "/flyus-dlya-pajki-kakoj-vybrat/" },
  smd_copper_yes:      { name: "Amtech RMA-223", type: "RMA", wash: true,  link: "/flyus-dlya-pajki-kakoj-vybrat/" },
  smd_copper_no:       { name: "No-clean гель MG-8341", type: "No-clean", wash: false, link: "/flyus-dlya-pajki-kakoj-vybrat/" },
  steel_any_yes:       { name: "Активный ФТС / ЛТИ-120", type: "RA", wash: true, link: "/flyus-dlya-stali/" },
  // ... полная таблица в JSON-файле
};

const state = {};
document.querySelectorAll('.choices button').forEach(btn => {
  btn.addEventListener('click', () => {
    state[currentStep] = btn.dataset.value;
    advanceWizard();
  });
});

function getResult() {
  const key = `${state[1]}_${state[2]}_${state[3]}`;
  return FLUX_DB[key] || FLUX_DB['wires_copper_yes']; // fallback
}
```
